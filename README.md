# 🎯 81kg → 65kg 专属减脂计划与每日打卡手册

> **个人档案与核心原则**
> - **基础数据**：身高 `170cm` ｜ 初始体重 `81.0kg (BMI 28.0)` ｜ 目标体重 `65.0kg (BMI 22.5)` ｜ 目标减重 `16.0kg`
> - **重点攻克部位**：肚子（内脏与皮下脂肪）、大腿（外侧与内侧）、脸部与脖子（水肿与探颈体态）
> - **不长块状肌肉铁律**：**每日 500~600 大卡热量缺口 + 低阻力中低心率有氧（120~140次/分）+ 零大重量负重 + 每次运动后 15 分钟深度拉伸**。

## 一、 每日必做打卡清单（日常模板）

每天按时间轴逐项勾选，完成 **8 项以上** 即为合格燃脂日！

### ☀️ 早间唤醒（07:30 - 08:30）
- [ ] **07:30 空腹排毒水**：起床喝 `300ml` 温开水（可加一杯无糖黑咖啡帮助脸部消水肿）
- [ ] **08:00 优质早餐**：1拳头慢碳（红薯/玉米/燕麦/全麦面包）+ 1~2个鸡蛋 + 250ml无糖豆浆/牛奶 + 1把果蔬

### 🌤️ 日间控糖与消肿（10:30 - 16:00）
- [ ] **10:30 上午饮水**：慢饮 `500ml` 温水或绿茶，每久坐 1 小时起身活动 2 分钟（防大腿水肿）
- [ ] **12:00 减脂午餐（7~8分饱）**：按 **「汤水 → 2拳头蔬菜 → 1掌心瘦肉/鱼虾 → 1拳头主食」** 顺序进食
- [ ] **12:30 饭后消肚腩**：靠墙站立或慢走 `15 分钟`（后脑勺、肩胛骨、臀部、小腿肚、脚跟贴墙，收腹收下巴）
- [ ] **15:30 下午饮水/控饿**：慢饮 `500ml` 温水（若饿可吃 1 根黄瓜 / 1 个小苹果 / 10 颗巴旦木）

### 🌙 晚间燃脂与修复（17:30 - 23:00）
- [ ] **18:00 清淡晚餐（6分饱）**：**少盐少酱**（防次日脸肿）！1掌心豆腐/鱼虾/鸡胸 + 2拳头绿叶菜 + 半拳头粗粮（或不吃主食）
- [ ] **18:30 开启 16+8 断食**：18:30 后除喝白水外不再进食任何零食、水果、宵夜
- [ ] **19:30 核心与天鹅颈激活（10分钟）**：真空腹呼吸 10 次 + 死虫式 3 组 + 平板支撑 3 组 + 麦肯基收下巴 2 组
- [ ] **19:45 低冲击有氧燃脂（45分钟）**：快走 / 低冲击操 / 椭圆机 / 游泳（心率控制在 `120~140 次/分`）
- [ ] **20:30 瘦腿与肩颈深度拉伸（15分钟）**：大腿前侧 + 大腿后侧小腿 + 大腿内侧 + 臀腿外侧 + 肩颈拉伸
- [ ] **21:30 睡前消肿与全天饮水达标**：全天总饮水满 `2200~2500ml`，温水泡脚 `15 分钟`
- [ ] **23:00 准时入睡**：不熬夜（防皮质醇升高导致肚子长肉），保证 7~8 小时睡眠

### 2. 动作要点速查（防粗腿、专减肚子与脖子）

1. **核心与天鹅颈（10 分钟，有氧前做）**
   - **真空腹（收腰围神技）**：深吸气鼓肚子 → 缓慢吐气同时把肚脐眼拼命往脊柱贴，屏住 15~20 秒 × `8~10 次`。
   - **死虫式（平小腹）**：仰卧后腰死贴垫子，手脚抬起呈90度，交替伸直对侧手脚不落地，每组 16 次 × `3 组`。
   - **平板支撑**：收紧腹臀呈直线，每次 30~45 秒 × `3 组`。
   - **麦肯基收下巴（瘦脖子与双下巴）**：目视前方，食指轻推下巴水平向后平移（后颈拉长感），保持 5 秒 × `15 次 × 2 组`。
2. **低冲击有氧（45 分钟，心率 120~140）**
   - **快走要领**：配速 `5.5~6.5 km/h`，脚跟先着地滚到全脚掌，**用臀部和大腿根带动迈步，不要用小腿肚发力猛蹬**。
   - **器械要领**：椭圆机或单车只用 `1~3 档低阻力`，轻快踩踏，绝不调高阻力硬踩。
3. **运动后必做深度拉伸（15 分钟，拉长腿部与颈部线条）**
   - **大腿前侧**：站立扶墙后抓脚踝贴臀，双膝并拢、骨盆前推，左右各 `45秒 × 2组`。
   - **大腿后侧与小腿**：弓箭步推墙，后腿伸直、脚跟死踩地面，左右各 `45秒 × 2组`。
   - **大腿内侧**：坐姿脚心相对（蝴蝶式），膝盖下压、上身前倾，保持 `60秒`。
   - **大腿外侧与臀部**：仰卧翘二郎腿抱膝（4字拉伸），左右各 `45秒`。
   - **天鹅颈与斜方肌**：沉肩坐直，头向左侧偏、右侧偏、仰头拉颈前侧，各保持 `30秒`。
